Aim of the course: 
This course is intended to develop students' understanding of AI-powered DevOps tools and practices for 
modern software engineering. It focuses on the application of Large Language Models (LLMs), prompt 
engineering, intelligent code analysis, Retrieval-Augmented Generation (RAG), AI-assisted testing, and 
workflow automation throughout the software development lifecycle. 
 
Course Overview and Context: 
 
The integration of Artificial Intelligence with DevOps is transforming the way software is developed, tested, 
and delivered. This course introduces students to Large Language Models (LLMs), prompt engineering, 
semantic code understanding, Retrieval-Augmented Generation (RAG), AI-powered testing, and intelligent 
workflow automation. Students will acquire practical skills in AI-assisted code analysis, AI-enhanced CI/CD, 
and modern DevOps practices using state-of-the-art AI tools. By the end of the course, students will be able 
to design and implement AI-augmented software development pipelines. 
 
 
 
Course Philosophy 
This course is delivered using a Project-Based Learning (PjBL) approach, where students progressively design, 
develop, and deploy an AI-powered DevOps solution throughout the semester. The course bridges modern 
software engineering, DevOps practices, and Generative AI by integrating theoretical concepts with hands-on
implementation using state-of-the-art AI-assisted development tools. Students gain practical experience in 
leveraging Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), intelligent code 
assistants, and AI-driven automation to improve software development, testing, deployment, and 
maintenance workflows. 
Throughout the course, students progressively build an end-to-end AI-enabled software engineering solution 
by integrating concepts of: 
• 
AI-Assisted Software Development and Prompt Engineering  
• 
Semantic Code Search and Repository Intelligence  
• 
Large Language Models (LLMs) for Code Understanding and Generation  
• 
Retrieval-Augmented Generation (RAG) for Intelligent Code Retrieval  
• 
AI-Driven Testing, Debugging, and Code Quality Assessment  
• 
AI-Enhanced CI/CD and DevOps Workflow Automation

Experiential Learning Component (45 %): 
The Experiential Learning Component of the Intelligent Developer Tools and AIDevOps (CSE 4011) Workflows 
course is designed to provide students with hands-on experiences that reinforce theoretical knowledge through 
practical application. Throughout the course, students will engage in project-based learning where they will be 
assigned practical projects that evolve from foundational code intelligence tools to advanced AI-augmented 
DevOps workflows. These projects, which span the entirety of the course, are structured into phase-wise 
evaluations to ensure consistent application and progression of skills. 
The first project phase evaluation, scheduled for the week starting 21st September with a weightage of 30%, 
focuses on the fundamentals of AI-augmented code understanding and navigation. This includes setup and 
usage of tools such as Sourcegraph OSS and VS Code AI extensions (e.g., TabNine), prompt engineering for 
intelligent code completion and refactoring, and hands-on interaction with open-source AI code models. 
Students will be assessed on their ability to configure tools, navigate codebases, engineer prompts, and 
document their implementation. 
The second project phase, starting the week of 5th October and also weighted at 30%, emphasizes the 
integration of multiple tools and concepts including LangChain, LlamaIndex, and GitHub Actions. Students will 
work on building a RAG-based code Q&A bot, automate DevOps workflows using GitHub Actions and 
Sweep.dev, and integrate AI tools like CodiumAI and Codeium for intelligent test generation and bug detection. 
Evaluation will focus on effective integration of AI tools, workflow coherence, automation accuracy, and overall 
quality of code and documentation. 
 
 
Assessment Pattern: The final grade will be determined by the marks or grades earned during the project’s 
phase-wise evaluations and the end-term assessment. Grading will be conducted using the relative grading 
method outlined in the university’s academic regulations. To be eligible for grading, students must achieve a 
minimum of 40% of the total marks upon completing all assessments listed in the table below:

Student Responsibilities: 
– Attend lectures and do the work Lab Assignments as per instructions. 
– Participate in the discussions/assignments held during classes. 
– Check announcements on the LMS and emails regularly. 
– Submit the assigned task on time. 
– Regularly check marks on the LMS to ensure they are up to date. 
– Participate in class and take necessary actions to grasp the material. Asking questions is encouraged. 
– Communicate any concerns by speaking directly with the instructor. 
Attendance Policy: Students are expected to attend classes regularly. Failure to follow the classes regularly and 
adhere to the expected attendance percentage will result in losing quiz/lab marks and a reduction of the grade 
as per the University’s grading policy. 
Recourse Examination Policy: In case a student fails the course, a one-time recourse is permitted as per the 
academic regulations of the University. Recourse is allowed only for the End Semester examination. 
Make-up policy: No make-up exam will be conducted for unexcused absences. The faculty needs to be informed 
in advance in case the student is not going to appear for any evaluation component, and it is at the discretion 
of the faculty to sanction makeup for an evaluation component. 
Behavior Expectations: No mobile phones and other distractive gadgets are permitted in the class. 
Academic Dishonesty/Cheating/Plagiarism: Plagiarism and dishonesty in any form in any evaluation 
component will lead to appropriate disciplinary action.
